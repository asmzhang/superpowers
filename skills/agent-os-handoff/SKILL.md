# Agent OS Handoff

## Use when
- The current phase is complete.
- You need to transfer context cleanly.
- You need a validated next step.

## What it produces
- Completed work summary
- Project state
- Work intent
- Current phase
- Decisions made
- Assumptions
- Open questions
- Deferred items
- Recommended next phase

## Must not do
- Do not re-open solved questions.
- Do not invent missing facts.
- Do not mix in implementation work.

## Handoff
If another phase is still required, point directly to that phase. Otherwise, close the loop with a clear next action.
