# Agent OS Direction

## Use when
- The request needs clarification of goals or scope.
- The current behavior has drifted from the desired outcome.
- The user needs options and trade-offs before planning.

## What it produces
- Aligned goal statement
- Scope boundaries
- MVP or target outcome
- Options with trade-offs
- Recommended direction

## Must not do
- Do not start implementation.
- Do not turn unresolved goal conflicts into a plan.
- Do not ignore drift or scope conflict.

## Handoff
If the target is clear and the work can be broken down, hand off to `03 Planning`.
If the target is still uncertain, return to `01 Discovery`.
